# Tasks

Binding constraints that apply to EVERY task below (restated from CLAUDE.md so this file is executable on its own):

- Package manager is **Yarn 1.22** — use `yarn`, never `npm` or `pnpm`.
- **Never run bare `tsc`** to validate: it reports false positives from `lib.dom` vs `lib.webworker` conflicts inside `node_modules`. Validate with `yarn lint`, `yarn test`, and the actual webpack builds.
- This fork ships **portable-only**. Paths are re-derived at launch; never assume an installed-mode layout.
- Frontend code must import platform capabilities from `src/frontend/platform`, never directly from `fs-extra`, `electron`, Node `path`, or `common/ExifIO`.
- The desktop GUI path must behave **identically** when `--serve` is absent. Any desktop regression is a defect in this change, not an acceptable trade.
- Tasks marked **REQUIRES MANUAL EXECUTION** need Windows/GUI verification by a human with concrete evidence recorded (see `docs/TODO/QA-DISCIPLINE.md`).
